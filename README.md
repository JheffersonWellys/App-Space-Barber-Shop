# App Space Barber Shop
Seja bem vindo ao nosso aplicativo Space Barbe Shop.   
# Descrição do Projeto
Esse aplicativo foi idealisado para o Projeto Integrador, pelo curso de  Programação de Dispositiveis  Moveis. Foi desenvolvido pra  diminuir as filas nas barbearias e realizar agendamentos dos serviços disponiveis da barbearia .
Usamos as tecnologia do figma para criar o design das telas, o Android Studio para a programação do aplicativo utilizando a linguagen Java, o Git,Gitbash e Github para o controle de versionamento, o firebase para controle do banco de dados,
autenticação de usuarios e controle  de agendamentos.
