# App Space Barber Shop
Seja bem vindo ao nosso aplicativo Space Barbe Shop.   
# Descrição do Projeto
Esse aplicativo foi idealisado para o Projeto Integrador, pelo curso de  Programação de Dispositiveis  Moveis. Foi desenvolvido pra  diminuir as filas nas barbearias e realizar agendamentos dos serviços disponiveis da barbearia .
Usamos as tecnologia do figma para criar o design das telas, o Android Studio para a programação do aplicativo utilizando a linguagen Java, o Git,Gitbash e Github para o controle de versionamento, o firebase para controle do banco de dados,autenticação de usuarios e controle  de agendamentos.
O maior desafio no projeto intregrador foi de como iriamos lançar uma aplicação para dispositivos moveis, ideais e o propósito no mercado de tecnologia e o público alvo.NEste projeto nós observamos a particularidade do desenvolvimento no Android Studio, tanto no trabalho desenvolvido quanto na implementação ultilizando a linguagem Java. Muitos estudos e correções na codificação para chegar em projeto bem estruturado para mostrar a visibilidade do aplicativo para o usuário.
# como instalar
Atualmente, a instalaqão é feita via pk. futuramente, o aplicativo estarára disponivel na pley Store. 
Para ultilizar pela primeira deve ser feito,  a istalção do aplicativo, primeiro voçê  deve fazer o cadastro, ultilizado do cliente o  Nome, Telefone, Cidade, Email e Senha e da Barbearia deve ser utilizado Razão social, CNPJ, Endereço, Email e Senha. você sera redirecionado para a tela de login e colocar seu email e senha. você vai para a rela de menu onde fazera o agendamento.
