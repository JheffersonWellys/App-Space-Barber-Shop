# 🚀 Space Barber Shop
Seja bem vindo ao nosso aplicativo Space Barbe Shop. 

## 📋 Descrição
O *Space Barber Shop* é um aplicativo que permite criar agendamentos de corte em barbearias, resolvendo o problema de controle de horários e eliminando a necessidade de esperar em filas para atendimento.

## 🎯 Objetivo
O principal objetivo do aplicativo é facilitar a reserva de horários específicos para cortes em barbearias.

## 🎯 Problemas Resolvidos
- Elimina a espera em filas.
- Facilita o controle de horários para barbearias e clientes.

 ## 📌 Recursos Principais
- Agendamento de cortes.
- Visualização de agendamentos.
- Escolha de corte e barbeiro.

## 💡 Motivação
A motivação para a criação deste aplicativo foi um desafio proposto pela professora Laura Ribeiro [GitHub](https://github.com/LauraCristinaRibeiro)  para o Projeto Integrador de finalização do curso de desenvolvimento de aplicação mobile no Senac.

## 🛠️ Tecnologias Utilizadas
- *Firebase*: Controle de acesso e banco de dados.
- *Figma*: Desenvolvimento do design e identidade visual.
- *GitHub*: Armazenamento e controle de versionamento.
- *Git Bash*: Versionamento dos arquivos do projeto.
- *Android Studio*: Programação do código fonte utilizando Java.

## 📋 Requisitos de Sistema
- Internet.
- Versão do Android Oreo+.

## 📝 Instalação
Atualmente, a instalação é feita via APK. Futuramente, o aplicativo estará disponível na Play Store.

## ⚙️ Configuração do Ambiente de Desenvolvimento
- Downgrade para a versão do Android Studio 2020.2 Patch 1.2.0.

## 🚀 Uso
Após a instalação, os usuários precisam de internet para criar uma conta e agendar um corte.
